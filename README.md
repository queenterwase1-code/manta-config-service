# safe-config-service

[![Coverage Status](https://coveralls.io/repos/github/safe-global/safe-config-service/badge.svg)](https://coveralls.io/github/safe-global/safe-config-service)

The `safe-config-service` is a service that provides configuration information in the context of the Safe clients environment (eg.: list of available safe apps and chain metadata).

## Requirements

- `docker-compose` – https://docs.docker.com/compose/install/
- Python 3.12.1
